# UI Streamlit - Детальный план реализации

## Общая концепция

Streamlit интерфейс для **Multimodal Real Estate Price Prediction** сервиса, который позволяет пользователям получать предсказания цен на недвижимость на основе изображений и метаданных.

## Основные функции UI

### 1. Главная страница / Инференс (Home/Prediction)

#### 1.1. Ввод данных через ссылку Airbnb
- **Поле ввода:** URL листинга Airbnb (например, `https://www.airbnb.com/rooms/12345678`)
- **Кнопка "Предсказать цену"**
- **Логика:**
  - Парсинг URL для извлечения listing_id
  - Запрос к Airbnb API для получения данных листинга
  - Загрузка изображений
  - Обработка через CLIP (или использование уже существующих embeddings из БД)
  - Отправка данных в ML-сервис для инференса
  - Отображение предсказанной цены

#### 1.2. Ручной ввод метаданных (альтернативный способ)
- **Форма с полями:**
  - Количество комнат
  - Площадь
  - Район/локация (dropdown или text input)
  - Тип недвижимости (dropdown: apartment, house, etc.)
  - Загрузка изображений (file uploader)
- **Кнопка "Предсказать цену"**

#### 1.3. Отображение результата предсказания
- **Карточка с результатами:**
  - Предсказанная цена (крупным шрифтом)
  - Основные факторы влияния (feature importance, если доступно)
  - Визуализация похожих листингов (опционально)

### 2. История предсказаний (History/Predictions)

#### 2.1. Таблица с историей
- **Колонки:**
  - ID листинга
  - Дата/время предсказания
  - Предсказанная цена
  - Фактическая цена (если доступна)
  - Ошибка (если есть фактическая цена)
  - Статус (new prediction, verified, etc.)
- **Фильтры:**
  - По дате (date range picker)
  - По диапазону цен (slider)
  - По району (multiselect)
- **Пагинация** (если записей много)

#### 2.2. Детальный просмотр записи
- При клике на строку - развернутая информация:
  - Все метаданные листинга
  - Изображения
  - График сравнения с похожими листингами

### 3. Аналитическая панель (Analytics/Dashboard)

#### 3.1. Общая статистика (KPI Cards)
- **Метрики:**
  - Всего предсказаний
  - Средняя предсказанная цена
  - Средняя ошибка (если есть фактические цены)
  - Количество листингов в базе данных
  - Средняя цена по районам

#### 3.2. Графики и визуализации
- **График распределения предсказанных цен** (histogram)
  - По всем предсказаниям
  - По районам (группировка)
  - По типам недвижимости

- **График временного ряда** (line chart)
  - Количество предсказаний по времени
  - Средняя цена по времени
  - Тренд цен

- **Тепловая карта цен по районам** (heatmap или map)
  - Если есть координаты (lat/lng)

- **Сравнение предсказаний vs фактические цены** (scatter plot)
  - Если есть данные для валидации

- **Топ факторов влияния на цену** (bar chart)
  - Feature importance из модели

#### 3.3. Фильтры для аналитики
- Выбор временного диапазона
- Выбор районов
- Выбор типа недвижимости
- Автообновление (checkbox)

### 4. Поиск похожих листингов (Similar Listings)

#### 4.1. Векторный поиск
- **Поле ввода:** ID листинга или загрузка изображения
- **Параметры:**
  - Количество похожих (slider: 1-20)
  - Минимальная схожесть (slider: 0-1)
- **Результаты:**
  - Карточки с похожими листингами
  - Изображения
  - Цены
  - Метаданные
  - Степень схожести (cosine similarity)

### 5. Экспорт данных (Export)

- **Кнопки экспорта:**
  - CSV с историей предсказаний
  - JSON с детальными данными
  - PDF отчет (опционально)

### Подключения

1. **PostgreSQL** - для истории предсказаний и поиска похожих листингов
2. **ML Inference Service** - HTTP API для получения предсказаний
3. **Kafka** (опционально) - для отправки запросов на инференс

### Дизайн и UX

- **Цветовая схема:** Использовать Streamlit theme с настройками
- **Навигация:** Sidebar с навигацией между страницами
- **Адаптивность:** Streamlit автоматически адаптируется
- **Загрузка:** Показывать progress bars при длительных операциях
- **Ошибки:** Понятные сообщения об ошибках с инструкциями

## Примерный flow пользователя

1. Пользователь заходит на главную страницу
2. Вводит ссылку на Airbnb листинг
3. Нажимает "Предсказать цену"
4. Система:
   - Парсит URL
   - Загружает данные из API (или БД)
   - Отправляет в ML-сервис
   - Получает предсказание
5. Отображает результат с визуализацией
6. Сохраняет предсказание в БД (через ML-сервис)
7. Пользователь может:
   - Посмотреть детали
   - Найти похожие листинги
   - Перейти в аналитику
   - Экспортировать данные

## Интеграция с ML-сервисом

### API Endpoint (ожидаемый)
```
POST /predict
Body: {
  "listing_id": "12345678",
  "metadata": {...},
  "embedding": [0.1, 0.2, ...]  # CLIP embedding
}
Response: {
  "predicted_price": 150.5,
  "confidence_interval": [140.0, 160.0],
  "feature_importance": {...},
  "similar_listings": [...]
}
```

### Альтернатива: Прямая работа с БД
Если ML-сервис недоступен, можно:
- Использовать сохраненные предсказания из БД
- Показывать исторические данные
- Векторный поиск для похожих листингов
